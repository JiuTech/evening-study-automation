# 半月晚自习公示自动生成器

 将半月晚自习群聊记录自动整理为规范化 Excel 公示表的浏览器端工具。

## ✨ 项目亮点

- 🚀 将人工整理流程自动化，减少重复性 Excel 操作
- 📱 支持手机和电脑浏览器使用
- 🔒 数据在浏览器本地处理，不上传姓名、学号和群聊内容
- 📊 自动完成名单匹配、缺勤/早退识别和 Excel 生成
- ⚠️ 支持异常识别和人工核对
- 🌐 支持 GitHub Pages 在线部署
- 🧪 包含核心规则测试
- 
## 使用方法

1. 双击 `start.bat`，或打开已发布的 GitHub Pages 地址。
2. 浏览器会自动打开软件页面。
3. 每台设备第一次使用时选择当前名单 Excel 模板；模板只保存在该浏览器中。
4. 设置月份、上下半月和两类实际检查天数。
5. 粘贴群聊文字或导入 `.txt`，点击“开始识别”。
6. 核对识别结果，尤其检查撤回、更正、请假和黄色提示。
7. 下载 Excel 公示表。

项目需要 Python 环境运行，本地启动脚本会尝试自动检测 Anaconda/Python 环境。

也可以在 PyCharm 中打开本项目，右键运行 `server.py`；运行后访问 `http://127.0.0.1:8765`。

请假会保留在核对页，但默认不计入缺勤率；真正进入公示表的是“缺勤”和“早退”。同一日期、同一类别、同一种情况被重复发送时，以最后一次报告为准。首次联网打开后，可以把网页安装到手机主屏幕或电脑；缓存完成后断网也能继续使用。

## 发布到 GitHub Pages

代码推送到 GitHub 的 `main` 分支后，`.github/workflows/pages.yml` 会自动发布 `static` 目录。在仓库 `Settings → Pages` 中把 `Source` 设为 `GitHub Actions`，部署完成后即可得到公网网址。

公开仓库中不要提交真实模板和聊天文本。`.gitignore` 已排除 `data/*.xlsx`、截图整理文本、输出文件和备份。网页要求每台设备本地选择模板，正是为了避免将真实名单发布到 GitHub。

## 建议的群聊格式

原工作方式不用改变，但每条消息尽量保持下面的结构，会明显降低人工校对量：

```text
12月3日
数学类
缺勤
2501 张三
2502 李四

早退
2501 王五
```

无人缺勤时写“无人缺勤”或“全勤”。请假名单前单独写“请假”。

## 更换新一届名单

在导出页展开“以后换新一届名单怎么办”，上传新的 `.xlsx` 模板。模板需保持以下结构：

- 第 1 行：标题；
- 第 2 行：`序号、姓名、班级、学号、出勤率、缺勤早退率、缺勤次数、早退次数、缺勤日期、早退日期`；
- 第 3 行起：学生名单；
- 班级名称中包含“数学类”的归入数学类，其他班级归入中外。

替换时，旧模板会保存到 `data/backups`，可以恢复。

## 项目结构

- `server.py`：可选的本地静态服务；
- `static/`：GitHub Pages/PWA 软件界面、浏览器内识别和 Excel 生成；
- `tests/`：核心规则与导出测试。

## GitHub 建议

模板和截图整理文本含姓名、学号等个人信息，不适合上传 GitHub。本项目已经在 `.gitignore` 中排除了这些文件和备份；即使使用私有仓库，也建议继续保持排除，只提交程序代码与脱敏测试材料。
