# 26级晚自习公示生成器

将26级晚自习群聊记录整理为原格式 Excel 公示表。

## 使用方法

1. 设置公示年份、月份、上/下半月和两类学生的检查天数。
2. 粘贴群聊文字，或导入 `.txt` 文件。
3. 点击“识别并核对”，检查缺勤、早退和请假记录。
4. 确认无误后下载 Excel 公示表。

26级名单已经内置，不再需要上传学生名单。系统只匹配内置名单中的姓名、班级和学号；无法匹配、班级不一致、日期不在所选半月等情况会在核对页提示。

## 处理规则

- 同一日期、同一类别、同一种情况重复发送时，以最后一次报告为准。
- “无人缺勤”“无人旷课”“全勤”“无缺勤”会清空对应报告中的缺勤记录。
- 请假保留在核对页，但不计入缺勤早退率。
- 缺勤和早退按学生、日期去重。
- 导出前再次检查名单归属、日期范围、重复记录和同日冲突。
- 输出表保持原公示表的标题结构、列顺序、名单、学号、边框和百分比格式。

## 数据说明

本仓库包含26级学生姓名、班级和学号，用于浏览器本地匹配和生成公示表。仓库为公开状态时，这些名单数据也会公开。群聊文字和生成过程仍在当前浏览器中完成，不会上传到应用服务器。

## 本地运行

```bash
streamlit run streamlit_app.py
```
